# Projek Ardana — Data Engineer Portfolio

Website portfolio profesional untuk Projek Ardana, Data Engineer yang berfokus pada pembangunan pipeline data yang reliable, teruji, dan siap digunakan.

## Isi portfolio

- Profil dan pendekatan kerja
- Showcase **Fashion Data ETL Pipeline**
- Keahlian: Python, Pandas, PostgreSQL, SQLAlchemy, Pytest, dan Google Sheets API
- Kontak langsung melalui email

## Menjalankan secara lokal

Website ini adalah static site tanpa build step. Buka `index.html` di browser atau jalankan server lokal:

```bash
python -m http.server 8000
```

Lalu kunjungi `http://localhost:8000`.

## Deploy

Website siap dideploy ke GitHub Pages, Netlify, Vercel, atau hosting static lainnya.
